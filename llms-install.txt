2. Work inside the user's intended directory; do not guess an ambiguous destination.
3. Create `.venv`; do not install into global/site Python.
4. Download the pinned wheel from the relative URL above.
5. Compute SHA-256 locally and compare the complete digest byte-for-byte. On mismatch, STOP.
6. Install the verified wheel with the venv Python using `python -m pip install <wheel>`.
7. Run `python -m specter_decision.cli capabilities` with the venv Python and confirm version 0.3.0.
8. Optionally run `python -m specter_decision.cli bench --batches 1 8 32 --iterations 100` to measure the current machine.
